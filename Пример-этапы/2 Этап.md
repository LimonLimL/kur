# Подключение БД.

## 1. Скачивание утилиты - `sqlx cli`. 

Поставить `sqlx cli` через `cargo install sqlx-cli`.

Проверка:

`sqlx --version`

## `sqlx-cli`

Справочная информация по SQLX cli:  `sqlx --help`

## 2. Создание миграции

```shell
sqlx migrate add <путь к папке> <название файла>
```


```shell
sqlx migrate add --source migrations/ items_initial # создает 1231213121_items_initial.sql
```

Создание схемы под свои сущности, например `Item`:

```rust
pub struct Item {
    pub(crate) id: Uuid,
    pub(crate) name: String,
    pub(crate) price: f32,
    pub(crate) created_at: UtcDateTime,
    pub(crate) updated_at: Option<UtcDateTime>,
    pub(crate) deleted_at: Option<UtcDateTime>,
}

```

```sql
CREATE TABLE items IF NOT EXISTS (
    id              BLOB PRIMARY KEY NOT NULL,
    name            TEXT NOT NULL -- String,
    price           REAL NOT NULL -- String ,
    created_at      TEXT NOT NULL -- UtcDateTime,
    updated_at      TEXT -- UtcDateTime,
    deleted_at      TEXT -- UtcDateTime
);
```


## 3. Создание первой базы данных `SQLite`.

3.1. Создать `.env`

3.2. Прописать строку подключения к базе данных:

```text
DATABASE_URL=sqlite://database/data.db
```

3.3.

```shell
sqlx db create # Создает базу данных на основе DATABASE_URL=sqlite://database/data.db
```

3.4.

```shell
sqlx migrate run --source ./migrations                                        
```

Если все успешно:

```shell
Applied 20260921061659/migrate items initial (2.840787ms)
```

## 4. Создание таблиц для остальных сущностей:

4.1. Создать пустую миграцию:

```shell
sqlx migrate add --source <путь к папке> <название миграции>
```

4.2. Расписать схему:

```sql
CREATE TABLE IF NOT EXISTS contracts (
    id              BLOB PRIMARY KEY NOT NULL,
    customer_id     BLOB NOT NULL,
    created_at      TEXT NOT NULL,
    finished_at     TEXT
);
```

Примеры:

```sql
CREATE TABLE IF NOT EXISTS items (
    id              BLOB PRIMARY KEY NOT NULL,
    name            TEXT NOT NULL,
    price           REAL NOT NULL,
    created_at      TEXT NOT NULL,
    updated_at      TEXT,
    deleted_at      TEXT
);
```

```sql
CREATE TABLE IF NOT EXISTS orders (
    order_id        BLOB NOT NULL PRIMARY KEY,
    customer_id     BLOB NOT NULL,
    item_id         BLOB NOT NULL,
    quantity        INTEGER NOT NULL,
    created_at      TEXT NOT NULL,
    finished_at     TEXT,
        
    CONSTRAINT customers_fk
    FOREIGN KEY (customer_id) REFERENCES customers(id),

    CONSTRAINT items_fk
    FOREIGN KEY (item_id) REFERENCES items(id)
);
```

**Схемы таблиц должны повторять набор данных ваших сущностей, созданных на предыдущем этапе**.

4.3. Применить миграции:

```shell
sqlx migrate run --source <путь к папкам с миграциями>.
```
