# Что было сделано:

1. Определиться какие будут сущности:

Сущности: товар, заказы, отгрузки.

2. Какие поля в сущностях:

## Товар

- код товара (UUID)
- Наименование товара (String)
- Цена товара (float)

## Заказы

- код заказа (UUID)
- код заказчика (UUID)
- количество товара (int)

## Заказчик

- код заказчика (UUID)
- наименование заказчика
- телефон (строка/уникальная) 

## Договор

- id договора (uuid)
- id заказчика (uuid)
- дата создания договора (String/Long)
- дата окончания договора (String/Long)

7. Реализация конструкторов для каждой структуры:

Для каждой структуры реализовать конструктор, пример:

```rust
pub struct Contract {
    pub(crate) id: Uuid,
    pub(crate) customer_id: Uuid,
    pub(crate) created_at: UtcDateTime,
    pub(crate) finished_at: Option<UtcDateTime>,
}

impl Contract {
    pub fn create_new(customer: &Customer, finished_at: Option<UtcDateTime>) -> Self {
        let id: Uuid = Uuid::new_v4();
        let created_at: UtcDateTime = UtcDateTime::now();
        Self {
            created_at: created_at,
            id: id,
            customer_id: customer.id,
            finished_at: finished_at,
        }
    }

    pub fn create(
        id: Uuid,
        customer: &Customer,
        created_at: UtcDateTime,
        finished_at: Option<UtcDateTime>,
    ) -> Self {
        let result: Contract = Contract {
            created_at: created_at,
            customer_id: customer.id,
            finished_at: finished_at,
            id: id,
        };
        result
    }
}
```

- **Созданы функции для инициализации каждой сущности:**

Пример:

```rust
#[doc = "Заказ
        Поля:
        - идентификатор заказа
        - идентификатор заказчика
        - количество товара
        "]
pub struct Order {
    pub(crate) order_id: Uuid,
    pub(crate) customer_id: Uuid,
    pub(crate) quantity: i32,
    pub(crate) created_at: UtcDateTime,
    pub(crate) finished_at: Option<UtcDateTime>,
}

impl Order {
    pub fn create(
        order_id: Uuid,
        customer: &Customer,
        quantity: i32,
        created_at: UtcDateTime,
        finished_at: Option<UtcDateTime>,
    ) -> Self {
        Self {
            order_id,
            customer_id: customer.id,
            quantity,
            created_at,
            finished_at,
        }
    }

    pub fn create_new(customer: &Customer, quantity: i32) -> Self {
        let id: Uuid = Uuid::new_v4();
        let created_at: UtcDateTime = UtcDateTime::now();
        Self::create(id, customer, quantity, created_at, None)
    }
}
```
